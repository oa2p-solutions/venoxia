# PR/FAQ · Checkout sin sorpresas

## El cliente ve el recibo de lo que pagó

Al confirmar el pago, el cliente recibe un recibo con el desglose exacto de lo cobrado,
sin tener que pedirlo.

## Una devolución libera lo que había reservado

Si el pago se revierte, el sistema deshace la reserva de existencias que ese pedido
había tomado: no se queda stock fantasma bloqueado.
